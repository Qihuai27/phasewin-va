# Greedy 与 PhaseWin 的尾部分布对比报告

本报告只研究 classification 任务。每个模型下使用三种本地评测设置：`true`、`cause`、`repair`。

## 统计定义

核心差值定义为：

```text
Gap = (Greedy Insertion AUC - PhaseWin Insertion AUC) * 100
```

因此，`Gap > 0` 表示 Greedy 在该样本上优于 PhaseWin。报告中将 `Gap > 10` 定义为极端 Greedy 优势样本，即 Greedy 的 Insertion AUC 比 PhaseWin 高 10 个点以上。

`Filtered Gap` 表示移除 `Gap > 10` 的极端 Greedy 优势样本后，重新计算的平均差值。

## 总体结论

Greedy 的平均优势确实明显集中在少数样本上，但并不是完全由少数样本造成。跨全部 27,000 个 paired samples，`13.1%` 的极端 Greedy 优势样本贡献了 Greedy 正向优势总量的 `53.7%`。移除这些样本后，整体平均差距从 `4.10` 点降到 `1.89` 点。

也就是说，更准确的表述是：

> Greedy 在多数样本上仍然略强，但报告中的平均优势有相当大一部分来自少数大幅领先样本；PhaseWin 在非极端样本上与 Greedy 更接近。

这些分位数说明 Greedy 优势分布有明显右尾。比如 CLIP RN101 true split 的 median gap 只有 `2.828` 点，但 q95 已达到 `23.391` 点，q99 达到 `36.600` 点。

## 解释

1. 所有设置中 `mean gap` 都大于 `median gap`，说明 Greedy 优势不是均匀分布，而是有明显尾部。
2. `repair` split 上尾部集中更明显，三个模型的 `Gap>10%` 都较高。
3. 移除 `Gap > 10` 的极端样本后，Greedy 仍保留约 `1.3` 到 `2.3` 点的平均优势，所以不能说 Greedy 只靠极端样本赢。
4. 更合理的结论是：Greedy 普遍略强，但其平均优势被少量高差距样本显著放大；PhaseWin 的优势在于用更少 forward 达到接近 Greedy 的非极端样本表现。
